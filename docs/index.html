Where the cliffs are.

A draft board is not a list of point estimates. It is an ordering, and a set of cliffs in that ordering. This project ingests rankings from several sources, resolves them onto one player identity, and computes where each position actually breaks — so the only question left on the clock is can I wait?

Two decisions shape everything here

Both are recorded as ADRs in the repository, because a decision that only lives in someone's head gets re-litigated every season.

Rankings, not projections

A projection of 214.6 points invites arithmetic on a number whose real uncertainty is tens of points wide. Where a source publishes only projections, we convert to a rank at ingest and discard the number — so it can never leak back into a tie-break or a column.

Public method, private source data

The primary source is a paid subscriber product. A subscription licenses one person to use those rankings, not to republish them. So the code, the method, and the site are public; the licensed rows are git-ignored and never leave the maintainer's machine.

Disagreement narrows a break

If the sources cannot agree which of two players goes first, those players are interchangeable and belong in one tier. A tier break survives only where the sources agree there is a real step down.

Guillotine is a different game

No playoffs, and the lowest-scoring team is chopped every week. The guillotine board re-ranks the same source for survival — mostly bye-week cover difficulty, which in an 18-team league is the difference between replacing a starter from an empty pool and from a dozen eliminated rosters. It shows every move against the ranker’s original board.

Rejections are data

Every row that fails to resolve to a canonical player — a name variant, a rookie, a mid-season trade — is retained with a reason and surfaced in the run report. Nothing is silently skipped.

The pipeline
